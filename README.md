Итоговый проект по дисциплине Веб-технологии

1. Агадуллина Ольга Евгеньевна 02141-ДБ

2. Графическая словесная игра «Последний полив». Правила основаны на известной текстовой игре «Виселица», с авторскими механиками (режим сложности с набором очков, система подсказок и комбо), которых нет в оригинальной версии. Планируется акцентировать внимание ещё и на визуале сайта — пикселизации с красивым оформлением природной тематики (сад), в дополнение добавить музыкальное сопровождение. В силу того, что игра имеет определённые достижения, она имеет свой логический конец и не является аркадной.

3. Главной целью сайта является расширение кругозора и словарного запаса у пользователей.

4. Целевая аудитория направлена на молодых людей (16–25 лет), увлекающихся интеллектуальными играми и пиксельной эстетикой. Также в аудиторию входят школьники в районе 12–14 лет, увлекающиеся мини-играми, или люди, изучающие русский язык. Благодаря пиксельной графике и малому весу проект доступен даже на старых устройствах, что привлекает аудиторию, ценящую быстрый запуск.

5. Содержание сайта:

* Весь сайт будет состоять из трёх страниц и дополнительных модальных окон (везде будет поддерживаться одна пиксельная и природная тематика).
* Первая страница сайта является приветственной, где будет объяснение правил игры, настройки (звука, сложности и др.), старт игры (ссылка на следующую страницу) и переход на третью страницу с достижениями.
* Следующая страница — основная, где будет возврат на главную, цветок слева экрана, визуально показывающий показатели текущей игры (сколько ошибок было допущено), геймплей в правой части — маска слова, кнопка для досрочного ввода слова, видимость количества отгаданных / ошибочных букв и счёта очков, снизу клавиатура из русских букв для ввода желаемой. Сверху цветка доступна кнопка для подсказок, которая может открыть любую букву слова на выбор (подсказки ограничены тремя попытками).
* Последняя страница представляет собой набор всех достижений в игре (выполненные и невыполненные), цель которой — мотивировать пользователя продолжать игру. Примеры достижений: набор максимального количества очков, шуточное достижение за проигрыш, за неиспользование подсказок и, наоборот, за использование всех, и др.

6. Функции и интерактив сайта:

* Адаптивность сайта (для ПК, планшетного экрана и телефона);
* Интерактив с клавиатурой во время игры на второй странице — выбор буквы при нажатии на неё из визуальной клавиатуры на экране;
* Анимация увядания и опадания лепестка (попытки) при неправильной букве;
* Изменение состояния цветка (начинает светиться) при наборе правильных букв подряд (комбо от двух правильно угаданных букв);
* Настройка сложности, звука и визуала игры;
* При повышении сложности (лёгкая, нормальная, сложная) количество допустимых ошибок (лепестков) уменьшается, соответственно меняется и цветок (роза — 7 лепестков, ромашка — 5, колокольчик — 3);
* При вводе двух неправильных букв сверху второй страницы всплывает модальное окно с интересным фактом об этом слове в качестве подсказки;
* Система начисления очков: +10 при угаданной букве, +50 при досрочном угадывании, –5 за ошибочную букву, 0 за подсказку. Максимум — 150, минимум (меньше — проигрыш) — 30.
